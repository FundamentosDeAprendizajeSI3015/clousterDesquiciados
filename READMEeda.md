# Análisis Exploratorio de datos (EDA)
En esta rama se realizará todo el analisis exploratorio de los datos trabajados durante el desarrollo del proyecto 

## Objetivo 
El objetivo de esta etapa es comprender la estructura y comportamiento de los datos, con el fin de identificar patrones, detectar posibles problemas y obtener información relevante que sirva como base para análisis o modelos posteriores.

## Alcance del análisis

* Inspección inicial de los datos

* Identificación de tipos de variables

* Detección de valores nulos o inconsistencias

* Cálculo de medidas de tendencia central (media, mediana, moda)

* Análisis de distribuciones de variables

* Identificación de valores atípicos (outliers)

* Exploración de relaciones entre variables


## Resultado Esperado 
Obtener un entendimiento claro del dataset que permita tomar decisiones informadas para las siguientes fases del proyecto (limpieza de datos, modelado, etc.).
