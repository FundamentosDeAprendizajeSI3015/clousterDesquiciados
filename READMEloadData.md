#  Data Loading & Cleaning Pipeline

Este repositorio contiene el código y los procesos necesarios para la **carga, limpieza y preparación de datos** de un dataset, con el fin de dejarlos listos para análisis o modelado.

##  Objetivo

El objetivo principal de este proyecto es transformar datos crudos en un formato limpio, estructurado y confiable, asegurando su calidad para etapas posteriores como análisis exploratorio (EDA), visualización o machine learning.

##  Alcance del proyecto

En este repositorio se desarrollan los siguientes procesos:

- **Carga de datos**
  - Lectura de archivos (CSV, Excel, etc.)
  - Conexión a fuentes de datos (si aplica)

-  **Inspección inicial**
  - Revisión de estructura
  - Identificación de tipos de datos
  - Detección de valores nulos o inconsistentes

-  **Limpieza de datos**
  - Manejo de valores faltantes
  - Eliminación de duplicados
  - Corrección de tipos de datos
  - Normalización y estandarización

-  **Transformación de datos**
  - Creación de nuevas variables
  - Filtrado de información relevante
  - Ajustes necesarios según el contexto del dataset
